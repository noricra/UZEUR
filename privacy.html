Politique de Confidentialité

Dernière mise à jour : Janvier 2025

1. Responsable du Traitement

Les données sont collectées par l'Éditeur du service (Particulier, France).
Pour toute question relative à vos données : support@uzeur.com

2. Données Collectées

Dans un souci de minimisation des données (Privacy by Design), nous ne collectons que le strict nécessaire :

  • Telegram : ID Utilisateur (numérique), Nom d'utilisateur (Username), Photo de profil.
  • Transactions : Adresses de portefeuille (Wallet) publiques, Hash de transaction (TXID). Ces données sont par nature publiques sur la Blockchain.
  • Fichiers : Les produits numériques téléversés par les Vendeurs.
  • Logs techniques : Adresse IP, logs d'erreurs pour la sécurité.

Note importante : Nous ne conservons aucune conversation privée. Le Bot fonctionne uniquement par commandes.

3. Partage des Données

Vos données transitent par nos prestataires techniques nécessaires au fonctionnement :

  • Telegram : Infrastructure de messagerie.
  • NowPayments : Traitement des adresses crypto.
  • Railway / OVH / Backblaze : Hébergement serveurs et stockage de fichiers (Europe & USA).

4. Durée de Conservation

  • Données de compte : Jusqu'à la demande de suppression ou fermeture du service.
  • Logs de transaction : Conservés pour la durée légale (5 à 10 ans) à des fins de preuve fiscale/juridique.
  • Fichiers produits : Supprimés à la fermeture du compte vendeur.

5. Vos Droits

Vous disposez d'un droit d'accès, de rectification et de suppression de vos données. Pour exercer ce droit, contactez support@uzeur.com.

Privacy Policy

Last Updated: January 2025

1. Data Controller

Data is collected by the Service Publisher (Individual, France).
For any data-related questions: support@uzeur.com

2. Data Collected

We collect strictly necessary data (Privacy by Design):

  • Telegram: User ID (numeric), Username, Profile Picture.
  • Transactions: Public Wallet Addresses, Transaction Hash (TXID). These are public on the Blockchain.
  • Files: Digital products uploaded by Sellers.
  • Technical Logs: IP Address, error logs for security.

Important: We do not store private conversations. The Bot operates via commands only.

3. Data Sharing

Your data passes through technical providers necessary for operation:

  • Telegram: Messaging infrastructure.
  • NowPayments: Crypto address processing.
  • Railway / OVH / Backblaze: Server hosting and file storage (Europe & USA).

4. Data Retention

  • Account Data: Until deletion request or service closure.
  • Transaction Logs: Retained for legal duration (5 to 10 years) for tax/legal proof.
  • Product Files: Deleted upon seller account closure.

5. Your Rights

You have the right to access, rectify, and delete your data. To exercise this right, contact support@uzeur.com.
